# WorkTime Sync

**Интеллектуальная система синхронизации рабочего времени с AI-рекомендациями**

WorkTime Sync — веб-платформа, которая автоматически анализирует занятость сотрудников, выявляет перегруженных и недозагруженных, предлагает сбалансировать нагрузку и помогает командам планировать встречи без конфликтов.

## Возможности

### Для сотрудника
- Профиль рабочего времени (часы, дни, часовой пояс, формат работы)
- Ввод фактических часов по проектам
- Заявки на отсутствие (отпуск, больничный)
- Персональный график загрузки
- AI-ассистент для вопросов о своей загрузке и доступности

### Для руководителя
- Дашборд с аналитикой команды: актуальность графика (Ai), конфликты (Ci), загрузка (Li), интегральный риск (Ri)
- Цветовая индикация (перегруз/недозагруз/норма)
- ML-балансировка (KMeans) — рекомендации по перераспределению задач
- Ручное добавление/удаление часов сотрудникам
- Командная карта доступности (часовые пояса, форматы работы)
- Дорожная карта актуализации (приоритетные действия)
- История изменений графиков
- Экспорт отчёта в Excel и PDF

### Для HR и аналитиков
- Общий график загрузки компании
- Экспорт в Excel (все записи) и PDF (сводка)
- Дорожная карта и история изменений

### AI-ассистент
- Локальная ML-модель (TF-IDF + логистическая регрессия) понимает намерения
- Отвечает на вопросы: «кто перегружен?», «лучшее время для встречи», «метрики Ивана»
- Подбирает общее свободное окно для командной встречи

### Технические детали
- **Backend**: FastAPI, Uvicorn
- **База данных**: SQLAlchemy + SQLite (легко заменить на PostgreSQL)
- **Аутентификация**: JWT + bcrypt
- **ML**: scikit-learn (KMeans, TF-IDF, LogisticRegression)
- **Визуализация**: Plotly
- **Шаблоны**: Jinja2 + Bootstrap 5
- **Экспорт**: openpyxl (Excel), reportlab (PDF)
- **Тестирование**: pytest (сервисы и API)
- **CI/CD**: GitHub Actions
- **Контейнеризация**: Docker + docker-compose

## Быстрый старт (локально)

```bash
python -m venv venv
source venv/bin/activate   # или activate.fish для Fish
pip install -r requirements.txt
python init_db.py
python fill_demo_data.py
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Откройте http://localhost:8000/auth/login
