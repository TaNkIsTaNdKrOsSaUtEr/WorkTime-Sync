## WorkTime Sync

**Система синхронизации рабочего времени с AI-рекомендациями**

WorkTime Sync — веб-приложение для автоматического сбора и анализа рабочего времени сотрудников. Помогает руководителям и HR контролировать загрузку команд, выявлять перегруженных и недозагруженных сотрудников и получать рекомендации по балансировке на основе машинного обучения.

---

### Основные возможности

- **Три роли пользователей**
  - _Сотрудник_ — ввод рабочих часов, просмотр личной статистики и графика загрузки, редактирование своего рабочего профиля (график, часовой пояс, формат работы).
  - _Руководитель_ — расширенный дашборд команды: цветовая индикация загрузки, аналитические метрики (актуальность, конфликты, риск), ручное добавление и удаление часов сотрудников, ML‑балансировка, командная карта доступности, управление проектами и заявками на отсутствие.
  - _HR_ — общий дашборд компании, экспорт отчёта в Excel.

- **Умная балансировка**
  Кластеризация сотрудников по средней загрузке (KMeans) и автоматическая генерация рекомендаций по перераспределению задач.

- **Расчёт показателей актуальности**
  Автоматический расчёт и отображение ключевых метрик: актуальность графика (Ai), доля конфликтов (Ci), уровень загрузки (Li), интегральный риск (Ri). На основе метрик формируются простые текстовые рекомендации.

- **Ручное управление**
  Руководитель может вручную добавлять и удалять рабочие часы за любого сотрудника своей команды.

- **Командная карта доступности**
  Таблица с рабочими интервалами, часовыми поясами и форматами работы всех членов команды.

- **Экспорт в Excel**
  HR может выгрузить все записи о рабочем времени в файл `.xlsx`.

- **OpenAPI/Swagger**
  Автоматическая интерактивная документация API доступна по адресу `/docs`.

### Быстрый старт (Cachy OS / Linux)

1. **Клонируйте или скопируйте проект** в рабочую директорию.

2. **Создайте и активируйте виртуальное окружение** (Fish‑shell):
   ```fish
   cd WorkTimeSync
   python -m venv venv
   source venv/bin/activate.fish   # для Fish
   # или для bash/zsh: source venv/bin/activate
   ```

3. **Установите зависимости**:
   ```fish
   pip install -r requirements.txt
   ```

4. **Инициализируйте базу данных** (создаются таблицы и тестовые учётные записи):
   ```fish
   python init_db.py
   ```

5. **Заполните демо‑данные** (опционально, для наглядной демонстрации):
   ```fish
   python fill_demo_data.py
   ```

6. **Запустите сервер**:
   ```fish
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

7. **Откройте в браузере**:
   - Приложение: `http://localhost:8000/auth/login`
   - Документация API: `http://localhost:8000/docs`

### Демонстрационный сценарий

1. **Сотрудник Иван** заходит, видит график загрузки и форму ввода. Вводит часы за день. Может редактировать свой рабочий профиль (часы, пояс, формат).
2. **Руководитель** на своём дашборде видит расширенную аналитику по команде:
   - Цветовую индикацию загрузки.
   - Метрики актуальности (Ai), конфликтов (Ci), загрузки (Li), риска (Ri).
   - Простые текстовые рекомендации.
3. Нажав «Получить рекомендации по балансировке», запускает ML-модель. Система предлагает переместить часть задач между перегруженными и недозагруженными сотрудниками.
4. Руководитель может вручную добавить часы любому сотруднику команды или удалить записи.
5. Кнопка «Командная карта доступности» показывает рабочее время, пояса и форматы всех членов команды.
6. **HR** видит общий график загрузки компании и экспортирует отчёт в Excel.

### Особенности реализации

- **Гибридная аутентификация** – токен передаётся либо через заголовок `Authorization`, либо через куку `access_token`, что позволяет работать и браузеру, и Swagger.
- **ML‑модель на KMeans** – кластеризует сотрудников по средней загрузке за 7 дней и предлагает переместить часы от перегруженных к недозагруженным.
- **Аналитические метрики** – актуальность графика (Ai), доля конфликтов (Ci), уровень загрузки (Li), интегральный риск (Ri).
- **Полное покрытие ролей** – на каждом экране доступны только разрешённые действия.
- **Авто‑документация** – все маршруты описаны и доступны для тестирования через Swagger.
- **Серверный рендеринг** – Jinja2 + Bootstrap 5, без отдельного фронтенда.

### Соответствие кейсу №3 (хакатон)

Проект закрывает **~70% обязательных требований MVP** и **~50% дополнительных**. Реализовано:

- Профиль рабочего времени (часы, пояс, формат, исключения).
- Расчёт показателей актуальности, конфликтов, загрузки, риска.
- Командная карта доступности.
- ML-рекомендации по балансировке и простые текстовые рекомендации.
- Ручное управление часами (добавление/удаление руководителем).
- Ролевая модель (сотрудник, руководитель, HR).
- Экспорт в Excel.
- OpenAPI/Swagger.

Не реализовано: загрузка внешних данных, AI-ассистент, уведомления, история изменений (из-за ограничения времени).
